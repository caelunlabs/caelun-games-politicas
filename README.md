# Políticas de Privacidade — Jogos da Caelun

Páginas públicas das políticas de privacidade dos jogos da Caelun, servidas pelo GitHub Pages.

| jogo | página |
|---|---|
| Kito's Play | `kitos-play/privacidade/` |
| BardicShift | `bardicshift/privacidade/` |

## Por que este repositório existe

As lojas de aplicativos exigem uma **URL pública** de política de privacidade. Os repositórios dos jogos são
privados, e o GitHub Pages gratuito só serve repositórios públicos — então as políticas moram aqui, **e só elas**.
Nenhum código de jogo fica neste repositório.

## Para onde isto vai

O destino final é **`caelun.app/games`**, o catálogo dos jogos da Caelun, com a página de cada jogo e a sua
política. Quando essa página existir:

1. a política passa a ser servida lá;
2. **cada página deste repositório vira um redirecionamento** para o endereço novo — **a URL antiga não pode
   quebrar**, porque está registrada na Play Console;
3. só então a URL é trocada na Play Console.

## Regras

- **Nada de recurso externo** nas páginas: sem fontes, scripts, imagens remotas ou rastreadores. Uma política de
  privacidade não pode ela mesma chamar terceiros.
- **A política diz o que o jogo faz hoje.** Se o jogo passar a coletar qualquer dado, a página é atualizada
  **antes** de a mudança chegar a quem joga — e a data no topo muda junto.
- Mantido pelo **Game Office** da Caelun.
